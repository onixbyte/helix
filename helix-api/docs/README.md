# Helix API Docs

Vite + React Router + Fumadocs documentation app with OpenAPI support.

## Run

```bash
pnpm install
pnpm dev
```

Open these pages:

- `/api-reference`: OpenAPI interactive reference
- `/docs`: MDX docs pages

## Edit OpenAPI

Manually maintain:

- `openapi/openapi.yaml`

After changes, refresh the `/api-reference` page.
